# Imperfect Homelab

The guide to the homelab: install it from the public module library
([homelab-modules](https://github.com/ww4/homelab-modules)), then
learn how it is built so you can add to it. A Zola site, published at
https://ww4.github.io/imperfect-homelab.

The name is a hat tip to [Perfect Media Server](https://perfectmediaserver.com),
where this homelab started.

## Layout

```
content/<section>/      the nine sections, weight-ordered (0 start-here … 9 field-notes)
content/services/       GENERATED — one page per library module (see below)
templates/ static/      Zola theme, no external theme dependency
tools/gen-reference.sh  the generator: catalog.json + options.json → markdown
flake.nix               site package, the generator, and the freshness check
```

## For agents

`static/llms.txt` (what the site is, where to look), `static/llms-full.txt`
(the whole site as text, generated by `tools/gen-llms.sh` and checked for
freshness by `nix flake check`), `static/skills/homelab-install/SKILL.md`
(the install procedure as an Agent Skill) and the For-agents page under
Start here. Regenerate after editing content:
`tools/gen-llms.sh content https://ww4.github.io/imperfect-homelab > static/llms-full.txt`.

## Working on it

```sh
nix develop            # zola + jq
zola serve             # live preview at http://127.0.0.1:1111
nix build              # the site, as Cloudflare Pages will build it
```

## The Services section is generated

`content/services/` is produced from the library at the commit pinned in
`flake.lock` — its catalog (`nix eval .#catalog`) and a module-system
evaluation of every `homelab.*` option. It is committed so the site builds
without nix (Cloudflare Pages runs plain `zola build`), and
`nix flake check` fails if the committed copy differs from what the
generator produces.

To pick up library changes:

```sh
nix flake update homelab-modules
nix run .#gen-reference
git add flake.lock content/services
```

## Publishing

GitHub Pages, from the GitHub push-mirror of this repo (Forgejo is the
source of truth; a merge there lands on the mirror and
`.github/workflows/pages.yml` builds Zola 0.22.1 and deploys). The base URL
is the Pages URL, or the domain in `static/CNAME` when that file exists —
add it (one line, the bare hostname) and a CNAME record pointing at
`<org>.github.io` to put the site on its own name. The repo on GitHub must
be public for Pages on the free plan.

The installer ISO is not here (1.5 GB); it lives in a DigitalOcean Space and
the Install chapter links it with its checksum.
